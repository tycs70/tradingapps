The Windows installation ZIP and its SHA-256 digest are retained here so a downloaded repository copy includes the complete offline installer.

Current update: **1.0.1**, with Top 20 ARMED display and optional encrypted remembered token. Close the app before running the new installer; existing data is preserved. The original 1.0.0 installer remains available for reference.

Extract the ZIP, then double-click `INSTALL.bat`. The installer creates its own Desktop and Start Menu shortcuts and includes a private Python/Tk runtime. See the bundled `README_FIRST.txt` before connecting to Upstox.
